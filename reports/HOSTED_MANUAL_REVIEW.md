# Hosted smoke review (DeepSeek `deepseek-flash`)

Review basis: `reports/hosted_smoke.json` (initial hybrid retrieval), `reports/hosted_keyword_smoke.json` (deployed BM25), `reports/hosted_code_smoke.json` (static-analysis path), the pinned Zephyr source files under `data/raw/`, and the exact retrieved source URLs. The five public knowledge/log cases were run in both search modes; one synthetic code case was run separately. This is a **small smoke test**, not an estimate of general answer accuracy. The reports contain no API secret.

Automated checks in the deployed BM25 run: route 5/5, expected generation decision 5/5, valid citation **numbers** 4/4 document-grounded cases, and expected source file present in all 4. The code case routed to static analysis, generated an explanation, and found the expected diagnostic; it has no document citations, so numeric citation validation is not applicable. Valid numbers and source presence do not prove each claim is entailed by its cited passage. The manual review above is narrow and qualitative, and `g03` remains a useful failure-mode example for distinguishing a plausible fix from a proven diagnosis.
